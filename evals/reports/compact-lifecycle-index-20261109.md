## Implementation result

`lifecycle.py:compact_index` re-encodes the saved snapshot index on a deep copy: one `pages` registry of `[path, title]` for features, omitted candidates and owner pages; `files[].owners` with every file→owner edge (the plain view carried only counts); kept `unregistered`, `invariants` and unknown row keys; `selected: false` and `selected_without_record` against the saved `context.files`; one `reading` record for the snapshot-mode statements and one shared reader prefix. Access/`allowed_files`, path bases, peers, freshness and the native contract's identity plus `context` (capture time/status, source and runtime observations) stay inline. Native operational keys, `return_requirements`, read-only baseline prose, artifact limits and review meaning are named under `not_delivered` (`NOT DELIVERED`) by key path in the existing `--view all` or `--view summary` reader. `workflow.py`, the packet and the public `show` views are unchanged. The overflow notice also reports `index_bytes` and `budget_bytes`.

Actual private packet through the source adapter, synthetic SessionStart stdin, no host: first pass with everything inline was still undelivered (8,704 bytes; saved records 7,299; native contract 3,166). With the deferral it is delivered at 6,061 of 6,144 bytes (6,482 with the wrapper). Native contract inline 1,287 (sources/context 1,129), index 1,808, `not_delivered` 370. All six file→owner edges, the omitted candidate, unregistered flags, peers and source observations match the packet; the packet hash was unchanged. Both private results are held outside this repository under new names. The margin is 83 bytes, so a slightly larger packet of the same shape will opt out visibly.

Source checks: sanitized fixtures for shared owners, Unicode, missing titles, same path with different titles, unknown row metadata, selected-file indicators, deferred-key discoverability in the existing readers, packet/public-view non-mutation, a large operational contract, oversized source observations, many-owner overflow and malformed rows; existing safety tests retained. Host execution, agent use, review and release remain the coordinator's.
