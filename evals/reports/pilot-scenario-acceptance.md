# Pilot three-scenario wiki acceptance — 2026-10-15

Familiar self-review at a fixed project baseline; no independent agent trial.
The human supplied three concrete scenarios, exposing a gap in the previous broad
orientation survey. Finding a page or reading its lead is not enough to establish
that a developer can discover critical variants and field-level behavior.

| Scenario | Wiki-first result | Repair and source conclusion |
|---|---|---|
| Share a private entry to a public post with text/images | Auto-summary crosspost and citation bridge described, no full composition path | A new page separates publish-time abstract/link (media null), composer citation plus uploaded images, and missing unified article-to-composer entrance; record partial success/backlink limits |
| Test accounts versus production | An existing page already separates axes correctly | Expose concrete author/viewer/role/rollout examples and link from actual share and schedule entries; a test-account flag does not select a deployment |
| Public schedule view versus role-specific schedule differences | Separate mechanism pages existed; public entry did not reveal the comparison | A new comparison page covers owner/viewer, a profile-only public block, a shared organization schedule, a private per-user schedule, partition and conditional new/legacy variants; fix an obsolete gap description |

Skill change: require applicable latent variants to be discoverable from a feature
entry, trace copied/entered/uploaded/rendered fields, and distinguish combinations
from existing fragments. Do not prescribe every axis for unrelated projects.

Validation and limitations: see the pilot's own audit report. No posts, uploads or
DB mutations were performed, no live config snapshot or production deployment is
certified.

with final process exit 0. Browser followed all three paths, rendered 26 diagrams

six scenario queries ranked the intended explanation first. Skill helper tests:
66 cases, 65 pass and one Windows symlink skip; frontmatter validation passed.
These results establish navigation and selected source checks, not live sharing.
