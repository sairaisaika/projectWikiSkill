This page is an **index** from each guarded behaviour to the code that enforces it and the
tests that guard it. The tests are the source of truth: if a row and a test disagree, the test
wins and this row is stale. A row whose Gap column is not "none" names a branch or case that
**no test** covers. Gaps are listed here, not filled in with invented tests.

### Routing overflow (0.2.31 candidate)

The6144-byte data budget never clips an inventory: a moderate overflow preserves every native routing edge/unknown per-file record, with full-index metadata explicitly deferred into the original snapshot reader; a huge routing inventory lists no paths and supplies exact bounded index/impact reader arguments. No Git/native command, new registry or reading/authority certificate. Guards: `tests/test_lifecycle.py » test_moderate_overflow_delivers_every_routing_edge_and_names_deferred_records`, `test_routing_that_cannot_fit_lists_no_file_and_supplies_an_exact_reader`, `test_utf8_budget_lets_a_unicode_index_fit_that_ascii_escaping_would_overflow`. Source and packaged execution are unit evidence; actual host/use are separate in status.

## Regenerating the test list

Run from the repo root to list every guarding test name with its class:

```sh
grep -nE '^class |    def test_' tests/*.py
```

At review time this gave 255 `def test_` methods in 15 files. The suite runs with
`python -m unittest discover -s tests -v`, the first of the two test commands in
[check.yml](../../.github/workflows/check.yml). The second runs `evals/fixture-project/tests`. When a test is renamed or
removed, fix the row here in the same change. A test name that no longer greps is a stale row.
